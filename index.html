Frequently asked

Is this a working payment system?

This build is a frontend demo. Requests, availability and ratings are simulated and stored on your device — no real payments or SMS are sent. See the badge on trip flows for "Demo" labeling.

Which towns are covered today?

Suleja, Kwamba, Madalla and nearby configured towns. New cities are added by an administrator without code changes.

How do operators get verified?

Operators submit basic profile and vehicle information for review. Verification status is shown clearly on every profile.
